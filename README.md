# Pop_Enviro_Data_Integration
Materials for the 2026 PAA Virtual Workshop Series titled Population and Environment Research - Linking Gridded Environmental Data to Public Population Data.

To view the knitted HTML document for this workshop, download the file titled: Environment_and_Population_Data.html. Open the file in a web browser.

To follow along with the training in your own RStudio environment, 
  1. Download the zipped folder titled: XXX and place it on your desktop.
  3. Install R on your machine. Download R here: https://cloud.r-project.org/
  4. Install RStudio on your machine here: https://docs.posit.co/ide/user/#rstudio-ide-oss-downloads
  5. Unzip the folder and double click the .RProj file to open the project.
  6. View the Environment_and_Population_Data.Rmd file in RStudio, using the "Visual" view setting rather than the "Source" view setting.
  7. Follow instructions in the .Rmd file.
